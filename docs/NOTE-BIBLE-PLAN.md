## 2. 노트 (N1~N3)

### N1. 편집창 위쪽 줄이기 — 본문이 화면 절반 아래에서 시작한다

- 지금: 분류 선택 / 닫기·글자수·📌🕘📤 / 위치·날짜 칸 / 제목 / 태그·계획참고·구상·블록 / 아이콘 9개 줄 / 서식 줄 → 본문은 460px 아래.
- 목표: 편집창을 열면 **제목 바로 아래에 본문**이 오게 한다. 나머지는 접어 둔다.
- 방법(덧붙이기 + CSS): 노트 편집창이 그려진 뒤(`DECO.add('노트 위쪽 접기',{root:'#v-note',deep:true,wait:150,run:fn,now:true})`)
  제목 입력칸과 `#nbw`(본문 상자) **사이에 있는 형제 요소들**을 `<details class="nxtra"><summary>⚙️ 분류·태그·도구</summary>…</details>` 안으로 옮긴다.
  서식 줄(되돌리기·굵게…)은 본문 상자 안에 있으므로 그대로 둔다. 이미 옮겼으면(`.nxtra` 있으면) 다시 하지 않는다.
  열림 상태는 `localStorage 'gj-nxtra'` 에 기억(기본 닫힘). 분류 선택 줄(맨 위 `📁 분류`)도 같은 details 안으로.
- 주의: 요소를 **옮기기만** 하고 다시 만들지 않는다(걸려 있는 이벤트 유지). 사람 노트(`n.person`)는 건드리지 않는다.
- 확인: `noteedit` 화면에서 본문 시작 위치가 250px 안쪽인지(`document.querySelector('#nbw').getBoundingClientRect().top`), 접힌 것을 펴면 태그·분류가 그대로 동작하는지.

### N2. 노트 목록 줄의 작은 단추 4개 → ⋯ 하나로

- 지금: 분류 줄마다 `개수 · 📅 · ＋ · ⋯` 가 다닥다닥 붙어 잘못 누르기 쉽다.
- 찾는 말: `function ntRow`, `function ntMenu`
- 방법: `ntRow` 에서 📅 단추를 빼고 `ntMenu`(⋯ 메뉴) 항목 맨 위에 `📅 날짜별로 보기` 를 넣는다(📅 가 하던 동작을 그대로 호출).
  ＋ 와 ⋯ 는 남기되 크기를 36×36px 이상으로(CSS).
- 확인: `note` 화면 사진, ⋯ 메뉴에서 날짜별 보기가 열리는지.

### N3. 노트 검색 결과에 앞뒤 글 보여주기

- 찾는 말: `function ntSearchHTML`
- 방법: 결과 줄마다 제목 아래에 **찾은 말 앞뒤 30자**를 작은 글씨로, 찾은 말은 `<mark>`. 본문은 `n.body`(HTML일 수 있음 → 태그를 지운 글자에서 찾기), 블록 노트는 `n.bdoc`.
  결과는 최대 50개, 넘으면 "더 보기".
- 확인: Playwright 로 `ntQ='본문';` 넣고 목록 다시 그린 뒤 `mark` 가 있는지.

## 3. 성경 (B1~B4)

### B1. 성경 말씀 검색 (지금 없음 — 가장 큰 빈칸)

- 찾는 말: 바로 가기 칸 `바로 가기 · 예: 요 3:16`, `function bbParse`
- 방법: 바로 가기 칸에 넣은 글이 `bbParse` 로 구절이 **아니면** 낱말 검색으로 처리한다.
  `const B=await bbLoad()` 뒤 66권을 돌며 `절.includes(q)` 인 것을 모은다(최대 200개, 2글자 이상일 때만).
  결과는 시트(`#sheet`, 다른 시트 만드는 방식 = `function ntSheet` 참고)에 `창 1:1 본문…` 목록으로, 찾은 말은 `<mark>`.
  줄을 누르면 `bbOpen(b,c,v)`. 위쪽에 `구약 n · 신약 n` 개수, 책 이름 칩으로 거르기.
- 주의: 31,000절 전체 검색은 한 번에 돌려도 100ms 안쪽이다. 따로 색인 만들지 말 것.
- 확인: `사랑` 검색 → 결과 수 > 0, 첫 줄 누르면 그 장이 열리는지.

### B2. 성경 첫 화면의 겹친 줄 없애기 (계획 화면 5번과 같은 문제)

- 지금: 맨 위 탭(성경·어성경·큐티·기도·암송·찬송)과 바로 아래 "성경·기도 바로가기" 표(읽기 일정·성경 전체·어성경·큐티·기도·암송·찬송·이어 읽기)가 **같은 곳으로 가는 단추**다.
- 찾는 말: `t:'오늘 말씀'` (바로가기 표를 만드는 곳), `▶ 이어 읽기`
- 방법: 바로가기 표를 기본으로 접는다(이미 `접기 ▴` 단추가 있음 → 그 접힘 상태의 **기본값만** 접힘으로). 오늘 말씀 한 줄은 접혀도 보이게.
  사용자가 편 적이 있으면 그 상태를 따른다.
- 확인: `biblehome` 사진에서 "성경 읽기" 카드가 화면 위쪽 1/3 안에 오는지.

### B3. 읽기 화면 위쪽 단추 정리

- 지금: 책 이름 옆에 🔖 ✍ 가− 가＋ 가 한 줄에 안 들어가 `가＋` 가 두 줄로 깨지고, 안내 글 두 줄이 늘 떠 있다.
- 찾는 말: `class="bbvnbar"`, `id="bbmk"`, `data-bbfs`
- 방법: (1) 안내 글(`절을 누르고 ✍️ 느낀 점을…`)은 `S.vnMode` 가 꺼져 있을 때 **처음 3번만** 보이게(`SET.bible.hintN` 을 세어 3 이상이면 숨김. 켜져 있을 때의 "✍️ 느낀 점 쓰기 켬" 은 그대로).
  (2) 가−/가＋ 는 한 단추 `가` 로 합쳐 누르면 작은 칸(가− 100% 가＋)이 펼쳐지게. CSS 로 `.bbhd` 가 줄바꿈되지 않게 `flex-wrap:nowrap`, 책 이름은 `min-width:0;overflow:hidden;text-overflow:ellipsis`.
- 확인: `bible` 사진에서 단추가 한 줄, 본문 첫 절이 260px 안쪽에서 시작.

### B4. 장 끝에서 한 번에 "다 읽음 + 다음 장"

- 찾는 말: `id="bbdone"`, 다음 장 단추(`출 12 ›` 를 만드는 곳)
- 방법: 장 맨 아래 `✓ 다 읽음` 옆에 `✓ 읽고 다음 장 ›` 단추. 누르면 `#bbdone` 이 하는 일(읽음 표시·습관 체크)을 한 뒤 다음 장을 `bbOpen` 으로 연다.
  이미 읽은 장이면 읽음 표시는 건드리지 않고 다음 장만 연다(읽음이 풀리면 안 됨).
- 확인: Playwright 로 누른 뒤 `bbS().read['1-11']` 이 오늘 날짜이고 `bbC===12` 인지.

## 4. 노트 ↔ 성경 잇기 (X1~X3)

### X1. 노트·일지 안의 성경 구절을 누르면 바로 그 말씀

- 목표: 노트 본문이나 하루 기록에 `요 3:16`, `출애굽기 11:1-3` 처럼 적혀 있으면, **읽기 화면(편집 중이 아닐 때)** 에서 밑줄 링크가 되고 누르면 말씀이 작은 창으로 뜬다.
- 찾는 말: `function memRefs`, `async function brefVerses`, 책 이름 `BBN`, 줄임 이름 `BBA`
- 방법: 덧붙이기. `function bbRefScan(el)` — `el` 안의 **텍스트 노드만** 돌며 정규식(BBN·BBA 이름 + 숫자`:`숫자, 뒤에 `-숫자` 선택)에 맞는 곳을
  `<a class="bref" data-bref="요 3:16">` 으로 감싼다. `contenteditable`·`input`·`textarea` 안은 건너뛴다.
  적용 위치: 노트 카드 목록(`function noteCard` 가 그린 것), 절별 느낀 점 목록, 하루 돌아보기의 읽기 전용 글. `DECO.add` 로 `#v-note`, `#v-review` 에.
  누르면 `brefVerses` 로 본문을 가져와 시트에 보여 주고 아래에 `📖 이 장 열기`(→ `bbOpen`) 단추.
- 주의: 저장된 글은 바꾸지 않는다(화면에 그릴 때만 감쌈).
- 확인: 노트 본문에 `요 3:16` 을 넣고 목록에서 `.bref` 가 생기는지, 누르면 시트에 "하나님이 세상을" 이 보이는지.

### X2. 성경 읽기 화면에서 "이 장에 쓴 내 글" 보기

- 목표: 어떤 장을 열면, 그 장에 대해 내가 쓴 것(절별 느낀 점은 이미 보임)에 더해 **그 장을 언급한 노트·큐티**가 장 끝에 목록으로 나온다.
- 찾는 말: `function bbVNList`, `NOTES`(Map), `function nTitle`
- 방법: 장을 그린 뒤(`renderBible` 을 감싸고 `bbView==='read'` 일 때) `[...NOTES.values()]` 중 제목·본문(태그 지운 글자)에
  `책이름 장:` 또는 `줄임이름 장:` 이 들어 있는 것을 찾아 `<details><summary>📒 이 장을 적은 노트 n개</summary>` 로 `#bbdone` 위에 넣는다.
  줄을 누르면 `nReturn='bible';ntOpenPage(id)`. 0개면 아무것도 넣지 않는다.
- 주의: 노트가 수백 개여도 장을 열 때 한 번만 돈다. 사람 노트(`n.person`)는 뺀다.
- 확인: `출 11:1` 이 든 노트를 만든 뒤 `bbOpen(1,11)` → 목록에 그 노트가 보이는지.

### X3. 일정 블록 ↔ 노트 ↔ 성경을 한 줄로 잇기

- 지금: 일정 편집창에서 메모를 쓰면 `저장하면 📒 노트 › 신앙 › 양육에 함께 들어갑니다` 로 노트는 만들어지지만, **그 노트에서 일정으로, 성경 읽기에서 그날 일정으로** 돌아가는 길이 없다.
- 찾는 말: `저장하면 📒`, `function planToActual`, `function bbToday`, `id="bbdone"`
- 방법 두 가지(둘 다 작게):
  1. 블록에서 만들어진 노트(블록 id 를 가진 노트 — `저장하면 📒` 근처에서 어떤 필드에 넣는지 먼저 확인)의 편집창 위쪽에
     `🗓️ 11.14. 06:15 형제들 양육` 칩을 달고, 누르면 `openDay(날짜)` 후 그 블록으로 스크롤.
  2. 성경 `✓ 다 읽음` 을 누르면, **그 시각에 걸친 실제 블록이 없을 때만** 알림(`toastAct`)으로
     `📖 출 11장 읽음 · 실제 한 일에 넣기` 단추를 보여 주고, 누르면 `D.time` 에 `{s:지금-15분,e:지금,act:'성경 읽기',cat:신앙 쪽 분류}` 를 넣는다.
     자동으로 넣지는 않는다(사용자가 눌러야 함).
- 확인: 1) 블록 메모 저장 → 노트 열기 → 칩 누르면 오늘 화면으로. 2) `bbdone` 누른 뒤 알림 단추 → `D.time.length` 가 1 늘어남.

## 5. 연동: 계획 · 오늘 · 평가 · 목표 · 나 (L1~L6)

### 조사 결과 (v457 에서 실제로 넣어 보고 확인)

올해 목표 `체중 75kg` → 이번 달 `주 4회 달리기` → 이번 주 `달리기 4번` 을 만들고, 오늘 계획·실제 블록 하나를 그 주 목표에 연결(`b.goal`)한 뒤 각 화면 글자를 찾아봤다.

| 화면 | 이번 주 목표가 보이는가 | 비고 |
|---|---|---|
| 계획 › 세우기 | 보임 (기둥 칸 `🎯1`) | 여기서만 적는다. **이룸 체크가 없다**(빼기 ✕ 뿐) |
| 계획 › 돌아보기 | **안 보임** | 기둥별 시간·점수만. 세운 목표를 이뤘는지 묻지 않는다 |
| 오늘 (시작·시간표·위쪽 카드) | **안 보임** | `goalBandHTML`(🎯 이번 주·이번 달 목표 띠)이 있지만 목표 › 사다리 화면에서만 쓴다 |
| 오늘 › 평가 | **안 보임** | 기둥 점수 줄에 그 기둥의 목표·목표 시간이 없다 |
| 목표 (기둥별) | 올해 목표만, `0%` | 아래 달·주 목표와 실행 시간이 올라오지 않는다 |
| 나 | **안 보임** | 좋아하는 것·감정만. 비전·역할·이번 주 방향과 끊겨 있다 |
| 블록 | 연결 표시 없음 | 목표 연결 칸이 **실제 블록 편집창에만** 있다(`kind==='time'`). 계획 블록은 계획 카드 ⋯ 메뉴에서만 |

즉 "세우기에서 적은 목표"가 **오늘·평가·돌아보기·목표·나 어디에도 다시 나타나지 않는다.** 아래 L1~L6 이 그 길을 잇는다.

공통으로 쓰는 것(이미 있음): `goalsAt(lv,per)`, `perKey(lv,date)`, `chain(date)`, `goalOpts(date,sel)`, `prog(g)`, `wkTarget()`(기둥별 주간 목표 시간),
`wkAgg(mon,M)`(주간 실제 시간), `pdFocusGet(lv,a)`(중점 기둥), `rlList()`·`rlOfBlock(b)`(역할), `saveGoalsSoon()`. 목표 모양: `{id,lv,per,title,done,doneAt,parent,tasks,area,kind}`.

### L1. 오늘 화면에 이번 주 목표 띠 (세우기 → 오늘)

- 찾는 말: `function goalBandHTML`, `function startHTML`, `function schedHTML`
- 방법: 오늘 화면 시간표 **바로 위**(날짜 줄 아래)에 `goalBandHTML()` 를 접힌 한 줄로 넣는다: `🎯 이번 주 목표 3 · 이룸 1 ▾`.
  펴면 목표마다 `☐ 달리기 4번 · 이번 주 1h · [＋ 오늘 계획에 넣기]`.
  - ☐ 체크 → `g.done=true;g.doneAt=today();saveGoalsSoon()`.
  - `＋ 오늘 계획에 넣기` → `openBlockEditor('plan')` 를 새 블록으로 열되 `act=g.title`, `goal=g.id`, `area=g.area` 를 미리 채운다(여는 방식은 ＋ 계획 단추가 하는 것을 따라 한다).
  - "이번 주 1h" = 이번 주 월~일 `o.time` 중 `b.goal===g.id` 인 블록의 분 합계(`cacheAll`/`allMap()`).
- 설정: `SET.gbandDay`(없으면 켬). '화면에 보일 것'(`#showcard`)에 체크 하나 추가.
- 확인: 띠에 `달리기 4번` 이 보이고, 체크하면 목표 화면에서도 이룸으로 바뀌는지.

### L2. 블록과 목표 잇기 — 계획 블록에서도, 블록 위에도 🎯

- 찾는 말: `data-pn="goal"`(그 앞의 `kind==='time'?`), `I('goal','🎯','연결할 목표',has.goal)`, 블록 그리는 곳 `class="sblk `, `function planToActual`
- 방법: (1) 편집창의 목표 칸을 **계획 블록에도** 보이게(`kind==='time'?` 조건을 빼되, 그 안의 '집중 시간' 단추 `#bgfoc` 는 실제 블록에서만).
  (2) 블록 글자에 `b.goal` 이 있으면 반복 표시 `🔁` 옆에 `🎯` 를 붙인다.
  (3) `planToActual` 은 이미 `goal` 을 그대로 복사한다 — 건드리지 않는다.
- 확인: 계획 블록 편집창에서 목표를 고르고 저장 → 블록에 🎯, 계획 복사한 실제 블록에도 🎯.

### L3. 평가에 그 기둥의 목표와 시간 (오늘 → 평가)

- 찾는 말: `function growthHTML`, 기둥 줄을 그리는 곳(슬라이더 `type="range"` 근처), `wkTarget()`
- 방법: 평가의 기둥 줄(🙏 신앙 … 💗 마음관리) 이름 아래에 작은 글씨 한 줄:
  `🎯 달리기 4번 · 오늘 1h / 하루 몫 1.1h`
  - 목표: `goalsAt('w',perKey('w',D.date)).filter(g=>g.area===k&&!g.done)` 의 첫 1~2개 제목. 없으면 목표 부분 생략.
  - 오늘 시간: `D.time` 중 그 기둥(`b.area||catArea(b.cat)`) 블록 분 합계. 하루 몫 = `wkTarget()[k]/7`. 목표 시간이 없으면 `/ …` 생략.
  - 둘 다 없으면 줄을 넣지 않는다(지금 화면과 같음).
- 주의: 점수 계산(자동 점수)은 **바꾸지 않는다.** 보여 주기만 한다.
- 확인: 건강 줄 아래에 `달리기 4번` 과 `오늘 1h` 가 보이는지.

### L4. 돌아보기에서 목표 결과 묻기 + 못 이룬 목표 넘기기 (평가 → 계획)

- 찾는 말: `function wkBoardHTML`(주), `function zbHTML`(달·분기·해), `✓ 마무리 →`
- 방법: 돌아보기(②) 맨 위, 레이더 그림 **앞에** `🎯 이 기간 목표 n개` 카드:
  목표마다 `[이룸] [못 이룸→다음으로] 제목 · 실행 3h · 연결한 블록 2개`.
  - `이룸` → `done=true, doneAt=today()`.
  - `못 이룸→다음으로` → 같은 내용의 목표를 다음 기간(`per` 를 다음 주·다음 달 키로)으로 **복사**하고 원래 것에는 `carried:true` 표시(지우지 않는다).
  - `✓ 마무리 → 다음 … 세우기` 를 누를 때 아직 고르지 않은 목표가 있으면 `uiConfirm` 으로 "못 이룬 목표 n개를 다음으로 넘길까요?" 한 번 묻는다.
- 확인: 주 돌아보기에서 `달리기 4번` 이 보이고, 넘기기를 누르면 다음 주 세우기 건강 칸에 같은 목표가 생기는지. 원래 목표는 그대로 남아 있는지.

### L5. 목표 화면에 아래 단계와 실행이 올라오게 (오늘 → 목표)

- 찾는 말: `function renderGoals`, 기둥별 보기에서 올해 칸을 그리는 곳(`올해`), `function prog`, `function focusDays`
- 방법: 올해(및 3년·10년) 목표 칸의 `0%` 아래에 한 줄: `이번 달 1 · 이번 주 1 · 이번 주 실행 1h`.
  - 아래 단계: `GOALS.list` 에서 `parent` 를 따라 내려가며 현재 달·주(`perKey`)에 속한 것의 개수.
  - 실행: 이번 주 `o.time` 중 `b.goal` 이 이 목표 **또는 그 자손** 인 블록의 분 합계.
  - 칸을 누르면 지금처럼 목표 상세가 열린다(동작 변경 없음).
- 주의: `prog()` 의 퍼센트 계산은 바꾸지 않는다. 줄만 덧붙인다.
- 확인: `체중 75kg` 칸에 `이번 주 실행 1h` 가 보이는지.

### L6. '나' 맨 위에 "지금의 나" 한 장 (전체 → 나)

- 찾는 말: `async function renderMine`, `#minebody`, `GOALS.me`, `pdFocusGet`, `rlList`
- 방법: `renderMine` 을 감싸 `#minebody` 맨 앞에 카드 `🧭 지금의 나`(`id="mnow"`, 있으면 내용만 갱신):
  1. 비전 선언 한 줄(`GOALS.me` 의 비전 필드 — 비전 선언 화면이 어느 필드를 쓰는지 `나의 비전 선언` 으로 grep 해서 확인). 없으면 `＋ 비전 적기` → `go('vision')`.
  2. 이번 주 ⭐ 중점 기둥(`pdFocusGet('w',today())`) 과 이번 주 목표 제목들(이룸은 ✓). 누르면 `go('plan')`.
  3. 이번 주 역할별 시간: `o.time` 블록을 `rlOfBlock(b)` 로 묶어 `🧔 아버지 3h · …` (역할이 하나도 없으면 생략).
  4. 지난 7일 하루 열매 평균(이미 계산하는 함수가 있으면 사용, 없으면 `o.verdict`/점수 합 평균). 누르면 `go('rv2')`.
- 주의: 읽기 전용 요약이다. 여기서 값을 고치지 않는다.
- 확인: `mine` 화면 맨 위에 카드가 있고 `달리기 4번` 이 보이는지.

## 6. 권하는 순서

연동 먼저: L1 → L2 → L3 → L4 → L5 → L6 (앞의 것이 뒤의 것의 재료다. L1·L2 로 목표가 오늘에 들어와야 L3~L6 에 보일 값이 생긴다).
그다음: B1(검색) → N1(편집창) → X1(구절 링크) → B2 → B3 → B4 → N2 → N3 → X2 → X3.

## 7. 하지 않기로 한 것

- 노트 편집기를 통째로 다시 만들기: 지금 편집기는 동작한다. 줄 수만 줄인다(N1).
- 성경 본문 색인 파일 만들기: 검색이 충분히 빠르다(B1).
- 구절 링크를 저장된 글에 박아 넣기: 글을 바꾸면 되돌리기 어렵다. 화면에서만 감싼다(X1).
- 자동 점수·목표 퍼센트 계산식 바꾸기: 연동은 **보여 주고 잇는 것**까지만 한다(L3·L5).
