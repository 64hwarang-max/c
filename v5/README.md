# 성장일지 v5

기둥(관계·재정·건강·업무·지식·습관·마음관리)을 중심으로 **계획 → 실행 → 기록 → 평가 → 다음 계획**을 돌리는 폰 앱.
소스는 모듈로 나누어 쓰고, 빌드하면 **index.html 한 파일**이 된다(기존 `build-apk.yml`이 그대로 읽는다).

## 명령

| 명령 | 하는 일 |
|---|---|
| `node tools/build.mjs --dev` | 시험판 빌드(`dist/index.html`, `dist/artifact.html`). 비어 있는 기기에 샘플 하루를 넣는다 |
| `node tools/build.mjs` | 배포용 빌드. `__BUILD__`는 워크플로가 채운다 |
| `node tools/release.mjs ../index.html` | 배포용으로 빌드해서 **지정한 경로**에 쓴다(경로 없으면 아무것도 안 함) |
| `npm test` | 단위 시험(`node --test test/*.test.mjs`) |
| `./test-ui/run-all.sh` | 폰 화면(400×850) 시험 전체. Python Playwright 필요 |

빌드는 구조 검사(`tools/lint.mjs`)를 먼저 통과해야 한다: MutationObserver·전역 덮어쓰기·setInterval 보정 금지, 계층 위반 금지.

## 구조

```
screens/   화면(그리기·입력만)           ← features를 부른다, 서로 부르지 않는다
features/  하는 일(저장·되돌리기)         ← 문서마다 주인 한 곳
domain/    계산(순수 함수)               ← 저장소·화면을 모른다
core/      날짜·저장소·스키마
migrate/   v4·v6 → v5 변환
native/    기기 연결(문 하나씩)           ← 앱이 아니면 모두 조용히 건너뜀
ui/        시트·토스트·이스케이프
main.js    모든 것을 이어 붙이는 유일한 곳
```

데이터 한 곳 원칙: 거래는 `day.fin`, 반복 완료는 `day.done`, 점수는 `day.scUser`(직접) > `day.scAuto`(자동 초안), 하루 노트는 `day.notes`.
저장 키는 `v5/…`. v4 문서는 건드리지 않는다.

## 점수·레벨

입력은 하루 기둥 점수(0~10) 하나. 하루 XP = Σ(점수 × 가중치), 가중치는 그 주 중점 기둥만 ×1.5. 기둥 레벨은 기둥 누적 XP, 전체 레벨은 전체 누적 XP. 계산은 `domain/score.js` 한 파일.

## 폰에서 써 보는 순서 (v4는 그대로 둔 채)

1. 저장소에서 `v5` 브랜치를 만든다.
2. 그 브랜치에서 `node v5/tools/release.mjs index.html`로 **루트 `index.html`을 v5 빌드로 바꾼다.**
3. 푸시하면 `build-apk.yml`이 그 브랜치 기준으로 APK를 만든다(`main`은 그대로).
4. 같은 `appId`라서 설치하면 업데이트가 되고, 첫 실행에서 기존 IndexedDB를 v5로 변환한다. 변환 전에 v4 원본을 `Documents/성장일지/성장일지-v4원본-날짜.json`으로 내보낸다(안 되면 앱 전용 폴더, 그것도 안 되면 변환을 멈춘다).
5. 마음에 들면 `v5` 브랜치를 `main`에 합친다.

## 이번 버전에 들어 있는 것 / 아직 없는 것

들어 있음: 오늘(계획·실행·마감, 빠른 입력, 끌어 옮기기), 주(중점·균형판·할 일·마무리), 기둥(레벨·목표·반복), 기록(노트·재정·독서·만남), 나(분류·사람·테마·백업·가져오기), 위젯·알림·뒤로가기 연결.

**아직 옮기지 않음**(v4에는 있음): 만다라트, 마인드맵, 둥둥 메모, 워치, 문자·통화 읽기, AI 호출, 드라이브·원드라이브 동기화, 캘린더 위젯(CalBridge), 음성 입력, 건강 연동, iOS·PWA 안내, 예산·자산·프로젝트 화면. 해당 데이터는 변환 때 그대로 보관한다(`v5/budget`, `v5/assets`, `v5/projects`, `v5/legacy`).
**일부러 뺌**: 찬송·성경 음악·성경 본문·큐티·암송·기도, 제자리, 연결 그래프, 화면 난이도, 메뉴 순서 옮기기, 영성 기둥.

## 시험하지 못한 것

실제 폰의 손가락 입력(길게 눌러 끌기와 스크롤), 실제 안드로이드의 문서 폴더 쓰기·알림 권한·위젯 갱신, 사용자의 실제 v4/v6 데이터 변환. 가짜 Capacitor와 합성 데이터로만 시험했다.
